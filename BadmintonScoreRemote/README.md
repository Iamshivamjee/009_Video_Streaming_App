# Badminton Score App - Remote Controller

A companion app for the Badminton Score App that runs on a second device to remotely control the score via Bluetooth LE.

## Features
- Connect to the main score display device via Bluetooth LE
- Increment/decrement scores for both teams
- Toggle server
- Reset game/match
- Simple, distraction-free interface

## Setup
1. Install dependencies: `npm install`
2. Run on second device: `npm run android` or `npm run ios`

## Usage
1. Open the main Badminton Score App on the display device
2. Open this Remote Controller on the controller device
3. Tap "Connect to Display" and select the display device
4. Use the buttons to control the score remotely
